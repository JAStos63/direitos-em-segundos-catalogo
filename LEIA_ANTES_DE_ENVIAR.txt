DIREITOS EM SEGUNDOS — ENVIO CORRETO AO GITHUB

IMPORTANTE: envie o CONTEUDO desta pasta para a raiz do repositorio.
Nao envie a pasta inteira como uma subpasta.

Na pagina principal do repositorio devem aparecer diretamente:
.github
docs
scripts
README.md
requirements.txt

A pasta docs deve conter diretamente:
.nojekyll
index.html
index.json
catalogos

No Windows, ative Exibir > Mostrar > Itens ocultos para ver a pasta .github e o arquivo .nojekyll.
